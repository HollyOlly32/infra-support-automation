# infra-support-automation
Автоматизация Ansible для настройки рабочей станции инженера поддержки

# Лаборатория автоматизации инфраструктуры и поддержки

## Обзор проекта
Этот репозиторий содержит решение для автоматизации на базе Ansible, предназначенное для развертывания и настройки высокопроизводительной рабочей станции для инженера поддержки в среде Fintech/Трейдинг.

Цель проекта — продемонстрировать принципы **Infrastructure as Code (IaC)** (инфраструктура как код), обеспечивая последовательное, воспроизводимое и безопасное развертывание окружения.

## Ключевые блоки автоматизации
* **Укрепление системы и инструменты:** Автоматическая установка диагностических утилит (`htop`, `net-tools`, `netcat-openbsd`, `curl`) и обновление всей системы.
* **Сетевая безопасность:** Автоматическое развертывание конфигурации OpenVPN клиента с защищенными правами доступа к файлам (`0600`).
* **Операционная эффективность:** Внедрение пользовательских алиасов Bash для ускорения анализа логов и поиска неисправностей.
* **Контейнеризация:** Оркестровка Docker-окружения, включая предварительно настроенный экземпляр **PostgreSQL 15** для локального тестирования базы данных.
* **Готовность к мониторингу:** Автоматическая установка бинарного файла **Prometheus Node Exporter** для обеспечения готовности рабочей станции к сбору метрик.

## Продемонстрированные технические навыки
* **Идемпотентность:** Все задачи разработаны так, чтобы их можно было запускать многократно без внесения противоречий в систему.
* **Управление переменными:** Централизованная конфигурация с использованием переменных Ansible для простого обновления версий программного обеспечения.
* **Управление секретами:** Чувствительные данные (например, пароли базы данных) вынесены в переменные Ansible и могут быть защищены с помощью `ansible-vault`.
* **Управление бинарными файлами:** Опыт автоматической загрузки (через `get_url`) и ручной установки системных бинарных файлов.

## Как запустить

1. Установите Ansible и Docker (Ubuntu 22.04/24.04):

   sudo apt update && sudo apt install -y ansible docker.io

   ansible-galaxy collection install community.docker

2. Запустите playbook:

   ansible-playbook -i inventory/hosts.ini playbook.yml --ask-become-pass -e "deploy_user=$USER" -e "postgres_password=ВашБезопасныйПароль" -e "vpn_server_address=vpn.вашакомпания.com"
    >  В Codespaces просто нажмите `Enter` (пароль не требуется). Если увидите ошибку перезагрузки, добавьте `--skip-tags "patch,upgrade"` к команде.
    
    > Если вы видите предупреждения `ignore_errors` о перезагрузке или сервисе Docker — просто игнорируйте их. PostgreSQL и Node Exporter всё равно будут работать. Если контейнер PostgreSQL не запустился автоматически, выполните:
> ```bash
> docker run -d --name test_trading_db -e POSTGRES_PASSWORD=ВашПароль -e POSTGRES_USER=postgres -e POSTGRES_DB=trading_db postgres:15
> ```

4. После завершения выйдите из системы и зайдите снова (или выполните: newgrp docker)

5. Проверьте работоспособность:

   docker exec test_trading_db pg_isready -U postgres

   curl http://localhost:9100/metrics | head -3
